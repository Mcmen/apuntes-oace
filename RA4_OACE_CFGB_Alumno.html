Introducción a Internet · Historia, funcionamiento y estructura

⏱️ 110 min
RA4 CE-a · Usar navegación web reconociendo estructura Internet (5%)
🎥 Vídeo · ¿Cómo funciona Internet?
📌 ¿Qué es Internet?

Internet es una red mundial de ordenadores conectados entre sí que utilizan el protocolo TCP/IP para comunicarse. No es "la nube" ni una entidad única: es una red física de cables submarinos, routers y servidores repartidos por todo el mundo.

📅 Breve historia:

  • 1969: ARPANET (precursor de Internet, creado por el ejército de EE.UU.)
  • 1983: Se adopta el protocolo TCP/IP → nace Internet moderno
  • 1989: Tim Berners-Lee inventa la World Wide Web (WWW)
  • 1993: Primer navegador gráfico (Mosaic)
  • 1998: Se funda Google
  • 2004: Nace Facebook
  • 2007: Primer iPhone → Internet móvil

🔧 Componentes de Internet

  • Servidores: Ordenadores que almacenan páginas y servicios
  • Clientes: Nuestros dispositivos (PC, móvil, tablet)
  • Routers: Dirigen el tráfico de datos
  • Cables submarinos: Fibra óptica bajo el mar
  • Satélites: Conexión en zonas remotas

🌐 World Wide Web vs Internet

Internet es la red física. La WWW es un servicio que funciona sobre Internet (páginas web, enlaces). No es lo mismo: el correo, la mensajería o los juegos online también usan Internet pero no son WWW.

🔑 Concepto clave

Cuando escribes www.google.es en el navegador, ocurre esto: el navegador consulta un DNS (traduce el nombre a una IP), se conecta al servidor de Google en esa IP, solicita la página, y el servidor envía el código HTML que el navegador interpreta y muestra.

🎥 Vídeo relacionado con el tema

▶ ¿Qué es un Navegador Web? →

📌 Navegadores web principales
  • Google Chrome: El más usado, rápido, muchas extensiones.
  • Mozilla Firefox: Código abierto, enfocado en privacidad.
  • Microsoft Edge: El sucesor de Internet Explorer, basado en Chromium.
  • Safari: Navegador por defecto en Apple (macOS, iOS).
  • Opera: Incluye VPN y bloqueador de anuncios integrado.
  • Brave: Enfocado en privacidad y bloqueo de rastreadores.

🧩 Partes de un navegador

  • Barra de direcciones (URL): Donde escribimos la web
  • Barra de búsqueda: Algunos navegadores la integran con la barra de direcciones
  • Botones de navegación: Atrás, Adelante, Recargar, Inicio
  • Pestañas: Para tener varias páginas abiertas
  • Marcadores (Favoritos): Guardar páginas para acceder rápido
  • Historial: Registro de páginas visitadas
  • Menú de configuración: Ajustes, extensiones, privacidad

⚙️ Configuración básica

  • Página de inicio: Qué web se abre al iniciar
  • Motor de búsqueda por defecto: Google, Bing, DuckDuckGo...
  • Guardar contraseñas: El navegador puede recordarlas
  • Bloqueo de ventanas emergentes: Evita publicidad molesta
  • Borrar datos de navegación: Historial, cookies, caché

🎥 Vídeo · Trucos de búsqueda en Google
📌 Operadores de búsqueda (Google)
  • "texto exacto" → Busca la frase exacta entre comillas
  • AND / OR → Combina términos (AND es implícito, OR se escribe)
  • -palabra → Excluye una palabra (ej: coche -eléctrico)
  • site:dominio.com → Busca solo en un sitio web
  • filetype:pdf → Busca archivos de un tipo específico
  • intitle:palabra → La palabra está en el título
  • inurl:palabra → La palabra está en la URL
  • @nombre → Busca en redes sociales
  • #hashtag → Busca hashtags

🔍 Ejemplos prácticos

  • "cambio climático" → Frase exacta
  • recetas cocina -huevo → Recetas sin huevo
  • site:wikipedia.org inteligencia artificial → Solo en Wikipedia
  • filetype:pdf examen resuelto → Buscar PDFs

📅 Filtros de búsqueda

  • Filtro por tiempo: última hora, 24h, semana, mes, año
  • Filtro por tipo: imágenes, vídeos, noticias, mapas, shopping
  • Filtro por color: en búsqueda de imágenes
  • Filtro por tamaño: imagen grande, mediana, icono

Seguridad web · HTTPS, certificados, phishing y fraudes

⏱️ 110 min
RA4 CE-d · Identificar seguridad web, riesgos y fraudes (30%)
🎥 Vídeo · Cómo identificar páginas seguras
🔒 ¿Cómo saber si una web es segura?
  • HTTPS: El candado en la barra de direcciones. Significa que la comunicación está cifrada.
  • Certificado SSL/TLS: Acredita la identidad del sitio.
  • URL correcta: Revisar que no haya faltas de ortografía (ej: "g00gle.com").
  • Política de privacidad: Toda web seria debe tener una.

🎣 Tipos de fraudes comunes

  • Phishing: Suplantación de identidad. Te llega un correo falso de tu banco.
  • Smishing: Phishing por SMS.
  • Vishing: Phishing por llamada telefónica.
  • Malware: Software malicioso (virus, troyanos).
  • Ransomware: Secuestra tus datos y pide rescate.
  • Spam: Correo basura no solicitado.

🛡️ Buenas prácticas de seguridad

  • No hacer clic en enlaces sospechosos.
  • Verificar siempre la URL antes de introducir datos.
  • Usar contraseñas diferentes para cada servicio.
  • Activar la autenticación en dos pasos (2FA).
  • Mantener el navegador y el sistema actualizados.
  • No descargar archivos de fuentes no fiables.
⚠️ Señales de alerta de phishing
  • El remitente no coincide con la empresa (ej: banco@paypal.ru)
  • El mensaje crea urgencia ("su cuenta será bloqueada en 24h")
  • Te piden contraseñas o datos bancarios por email
  • El enlace no apunta al dominio oficial (pasa el ratón por encima)
  • Faltas de ortografía o redacción extraña

Crear y gestionar una cuenta de correo electrónico

⏱️ 110 min
RA4 CE-f · Crear cuenta de correo en servidor web (10%)
🎥 Vídeo · Cómo crear un correo en Gmail
📌 Proveedores de correo gratuitos
  • Gmail (Google): 15 GB gratis, integración con Drive, Calendar
  • Outlook (Microsoft): 15 GB, integración con Office Online
  • Yahoo Mail: 1 TB gratis, pero más publicidad
  • ProtonMail: Correo cifrado, enfocado en privacidad
  • Zoho Mail: Plan gratuito para correo personal

📝 Estructura de un correo

  • nombredeusuario@dominio.com
  • Remitente (De): Quién envía el correo
  • Destinatario (Para): A quién va dirigido
  • CC (Copia carbón): Destinatarios secundarios (todos ven quién recibe copia)
  • CCO (Copia carbón oculta): Destinatarios ocultos (no se ven entre sí)
  • Asunto: Breve descripción del contenido
  • Cuerpo del mensaje: El contenido
  • Adjuntos: Archivos que se envían con el correo

⚙️ Pasos para crear una cuenta

  • Elegir proveedor (ej: gmail.com)
  • Hacer clic en "Crear cuenta"
  • Rellenar datos: nombre, apellidos, fecha de nacimiento
  • Elegir nombre de usuario (ej: ana.perez.2025)
  • Crear una contraseña segura (mayúsculas, minúsculas, números, símbolos)
  • Verificar con número de teléfono (en la mayoría)
  • Aceptar términos y condiciones
💡 Consejo sobre contraseñas

Una contraseña segura debe tener al menos 12 caracteres, combinar mayúsculas, minúsculas, números y símbolos. No uses la misma contraseña en varios servicios. Ejemplo: "Gato#Rojo2024" (fácil de recordar, difícil de adivinar).

Almacenamiento en la nube · Google Drive, OneDrive, Dropbox

⏱️ 110 min
RA4 CE-c · Transferir información (descargar, enviar, almacenar) (15%)
🎥 Vídeo · Qué es la nube y cómo funciona
☁️ ¿Qué es la nube?

La nube (cloud computing) es almacenar y acceder a datos y programas a través de Internet, en lugar del disco duro de tu ordenador. Los archivos se guardan en servidores remotos y puedes acceder desde cualquier dispositivo.

📁 Principales servicios de nube

📤 Cómo usar Google Drive

  • Accede con tu cuenta de Gmail
  • Subir archivos: Botón "Nuevo" → "Subir archivos" o arrastrar
  • Crear documentos: Nuevo → Documentos de Google
  • Compartir: Botón derecho → Compartir → Añadir personas o enlace
  • Descargar: Botón derecho → Descargar
🔑 Concepto clave

Los archivos en la nube NO ocupan espacio en tu disco duro (solo la sincronización local si instalas la aplicación). Puedes acceder a ellos desde cualquier ordenador o móvil con Internet.

Transferencia de archivos · Descarga, subida y compartición

⏱️ 110 min
RA4 CE-c · Transferir información (descargar, enviar, almacenar) (15%)
🎥 Vídeo · Descargar archivos de forma segura
📌 Métodos de transferencia de archivos
  • Descarga directa: Desde un enlace (Drive, Dropbox, web)
  • Correo electrónico: Adjuntar archivos (hasta 20-25 MB)
  • Servicios de nube: Compartir enlace
  • FTP (File Transfer Protocol): Para transferir muchos archivos (servidores)
  • WeTransfer / Smash: Servicios temporales para archivos grandes

📥 Descarga segura

  • Descargar solo de sitios oficiales
  • Verificar la extensión del archivo (.exe puede ser virus)
  • Escanear con antivirus antes de abrir
  • No ejecutar archivos .exe de origen desconocido
  • Desconfiar de páginas que piden instalar "códecs" o "plugins"

📤 Compartir archivos grandes

  • WeTransfer: Hasta 2 GB gratis, enlace válido 7 días
  • Google Drive: Crear enlace de descarga
  • OneDrive: Compartir enlace
  • MEGA: Encriptado y 20 GB gratis
⚠️ Peligro: archivos maliciosos

Los virus se esconden a menudo en archivos .exe, .scr, .bat, .zip con contraseña. No abras archivos de remitentes desconocidos, incluso si la extensión parece inofensiva (un .pdf puede tener macros maliciosas).

Foros y comunidades online · Redes sociales

⏱️ 110 min
RA4 CE-g · Usar otros servicios (foro, mensajería, P2P, videoconferencia) (20%)
🎥 Vídeo · Cómo usar foros correctamente
📌 ¿Qué es un foro?

Un foro es un espacio de discusión online donde los usuarios crean hilos (temas) y otros responden. Está organizado por categorías. Reddit es el foro más grande del mundo.

💬 Tipos de comunidades

  • Foros tradicionales: Forocoches, Mediavida, Foros de ayuda técnica
  • Reddit: Subreddits para cada tema (r/programacion, r/askspain)
  • Grupos de Facebook / LinkedIn: Comunidades dentro de redes sociales
  • Discord / Slack: Canales de chat organizados
  • Quora: Preguntas y respuestas

📝 Normas de etiqueta en foros

  • Leer las reglas antes de publicar
  • Usar el buscador antes de preguntar (evitar duplicados)
  • Ser respetuoso (no insultar, no trolear)
  • Escribir con ortografía y claridad
  • No hacer spam ni autopromoción
  • Aportar valor, no solo quejarse
🔑 Concepto clave

Los foros son una fuente de conocimiento inmensa. Antes de preguntar algo técnico (ej: "cómo configurar una IP en Ubuntu"), busca si ya hay respuesta. La comunidad valora a quienes investigan antes de pedir ayuda.

📌 ¿Qué es una red P2P?

P2P (Peer to Peer) significa "de igual a igual". En lugar de descargar un archivo desde un servidor central, los usuarios se conectan entre sí y se descargan fragmentos del archivo desde múltiples fuentes. Cuantos más usuarios compartan, más rápida es la descarga.

📡 Protocolos y clientes P2P

  • BitTorrent: El más usado actualmente. Clientes: qBittorrent, Transmission, uTorrent (con cuidado).
  • eMule / eDonkey: Clásico pero menos usado hoy.
  • Tor (red anónima): No es para descargas, sino para navegación anónima.

⚖️ Consideraciones legales y de seguridad

  • Legal: Linux (distribuciones), software de código abierto, contenido libre (Creative Commons).
  • Ilegal: Compartir películas, música, juegos o software con derechos de autor sin permiso.
  • Riesgos: Archivos infectados con malware, riesgo legal (multas), exposición de IP.
  • Alternativa legal: Plataformas de streaming (Netflix, Spotify) y tiendas digitales (Steam, Epic Games).
⚠️ Advertencia sobre redes P2P

En España, compartir contenido con derechos de autor sin autorización es ilegal y puede conllevar sanciones. Además, los archivos .torrent y los clientes P2P son un vector común de malware. Si usas P2P, hazlo solo para contenido libre o legal.

🔒 Modo incógnito / Privado

  • No guarda: historial, cookies, datos de formularios, contraseñas
  • Sí guarda: marcadores guardados, descargas
  • No es anónimo: tu proveedor de Internet (ISP) y los sitios que visitas siguen viendo tu IP
  • Atajos: Ctrl + Shift + N (Chrome/Edge), Ctrl + Shift + P (Firefox)

🛡️ Configuración de privacidad

  • Borrar cookies y caché: Periódicamente (configuración → privacidad)
  • No rastrear (Do Not Track): Activar (aunque no todos los sitios lo respetan)
  • Bloquear cookies de terceros: Evita rastreo entre sitios
  • Gestionar permisos: Qué sitios pueden acceder a ubicación, cámara, micrófono

🎥 Vídeo · Peligros de Internet
📌 Tipos de malware
  • Virus: Se propaga insertándose en archivos ejecutables.
  • Troyano: Se hace pasar por software legítimo, pero permite acceso remoto.
  • Gusano: Se propaga por la red sin necesidad de intervención humana.
  • Ransomware: Cifra tus archivos y pide rescate (Bitcoin).
  • Spyware: Espía tu actividad (keyloggers, captura de contraseñas).
  • Adware: Muestra publicidad no deseada.
  • Rootkit: Se oculta en el sistema, difícil de detectar.

🎭 Ingeniería social

Manipulación psicológica para que la víctima revele información confidencial o realice acciones. Ejemplos:

  • Phishing: Correo falso de entidad confiable.
  • Pretexting: Inventar una historia para obtener datos.
  • Baiting: Ofrecer algo atractivo (USB "perdido" con malware).
  • Quid pro quo: Ofrecer un servicio falso a cambio de datos.

🤝 Ciberacoso y grooming

  • Ciberacoso (Cyberbullying): Acoso mediante medios digitales (insultos, difusión de rumores).
  • Grooming: Adulto que se hace pasar por menor para ganarse la confianza y abusar sexualmente.
  • Sexting: Enviar imágenes íntimas. Puede derivar en sextorsión.
  • Qué hacer: Guardar pruebas, bloquear al acosador, no responder, pedir ayuda a un adulto o profesor.
💡 Cómo protegerte
  • Mantener el sistema operativo y el antivirus actualizados.
  • No descargar software de fuentes no oficiales.
  • No abrir archivos adjuntos sospechosos.
  • No compartir información personal en redes sociales públicas.
  • Usar contraseñas diferentes y seguras.
  • Activar la autenticación en dos pasos.
