Escenario empresarial

La empresa Reparaciones Eléctricas Hnos. Vidal S.L. acaba de recibir 12 equipos con Windows 11 y 6 equipos con Ubuntu 24.04. Debes dejarlos listos para los operarios de taller. Cada equipo debe tener el sistema operativo instalado y funcionando con los parámetros correctos de idioma, teclado, zona horaria, usuario, nombre de equipo y red.

Datos de la empresa:

  • Red local: 192.168.10.0/24
  • Puerta de enlace: 192.168.10.1
  • DNS: 8.8.8.8 y 1.1.1.1
  • Dominio interno: talleres.hernandezvidal.local
  • Usuario local: operario
  • Contraseña temporal: Manzana2026!
  • Nombre del equipo asignado: AULA-XX donde XX es tu número de puesto

Trabajarás sobre un equipo con Windows 11 y otro con Ubuntu 24.04, reales o virtuales. Para cada paso debes comprobar que el cambio se ha aplicado correctamente.

Objetivos

  • Configurar idioma, distribución de teclado y zona horaria en ambos sistemas.
  • Crear una cuenta de usuario local con contraseña.
  • Cambiar el nombre del equipo.
  • Verificar la red con DHCP y probar la conexión a Internet.
  • Aplicar actualizaciones y comprobar la protección básica.
  • Adaptar la configuración a una IP estática cuando la empresa lo solicite.
  • Diagnosticar y corregir fallos habituales en la configuración básica.
  • Documentar las intervenciones y presentar evidencias.

Práctica guiada · Nivel básico

BÁSICO

Sigue los pasos numerados. En cada paso tienes la ruta de Windows 11 y los comandos equivalentes en Ubuntu 24.04. Después de cada paso, comprueba que el resultado es correcto antes de continuar.

  1. Configurar idioma y distribución de teclado

    Windows 11

    Pulsa Win + I para abrir Configuración. Ve a Hora e idioma → Idioma y región. Añade el idioma Español (España), ponlo en la primera posición y revisa que el teclado sea Spanish (Spain).

    Comando PowerShell equivalente (opcional):

    Set-WinUserLanguageList -LanguageList es-ES -Force

    -LanguageList indica la lista de idiomas y -Force aplica el cambio sin pedir confirmación.

    Ubuntu 24.04

    Abre el terminal con Ctrl + Alt + T y ejecuta:

    sudo localectl set-locale LANG=es_ES.UTF-8

    Después configura el teclado:

    sudo localectl set-x11keymap es

    set-locale ajusta el idioma del sistema y set-x11keymap ajusta el mapa de teclado gráfico.

    Verificación: cierra sesión y vuelve a entrar. Los menús deben estar en español. Abre el Bloc de notas o gedit y escribe ñáéíóú; deben aparecer correctamente.

  2. Configurar zona horaria y formato de fecha

    Windows 11

    Ve a Configuración → Hora e idioma → Fecha y hora. Ajusta la zona horaria a Madrid y activa Establecer zona horaria automáticamente y Establecer hora automáticamente.

    Comando PowerShell equivalente:

    Set-TimeZone -Name "Romance Standard Time"

    -Name indica el identificador de zona horaria de Windows para Madrid.

    Ubuntu 24.04

    Ejecuta en terminal:

    sudo timedatectl set-timezone Europe/Madrid

    Comprueba con timedatectl que la zona horaria es Europe/Madrid.

    Verificación: la fecha y hora de la bandeja del sistema deben coincidir con la hora real del aula. En Ubuntu el comando date debe mostrar la hora correcta.

  3. Crear cuenta de usuario local

    Windows 11

    Ve a Configuración → Cuentas → Familia y otros usuarios → Agregar usuario. Selecciona No tengo datos de inicio de sesión de esta persona y después Agregar un usuario sin una cuenta Microsoft. Crea el usuario operario con contraseña Manzana2026!.

    Comando PowerShell equivalente:

    New-LocalUser -Name "operario" -Password (ConvertTo-SecureString "Manzana2026!" -AsPlainText -Force) -FullName "Operario de taller" -Description "Cuenta local de operario"

    -Name asigna el nombre de usuario, -Password la contraseña, -FullName el nombre completo y -Description una descripción. Dentro del paréntesis, -AsPlainText convierte la contraseña en texto plano y -Force evita la confirmación.

    Ubuntu 24.04

    Ejecuta en terminal:

    sudo useradd -m -s /bin/bash -c "Operario de taller" operario

    -m crea la carpeta personal del usuario, -s asigna la shell de inicio, -c añade el comentario o nombre completo.

    Asigna contraseña:

    sudo passwd operario

    Escribe Manzana2026! cuando el sistema lo pida.

    Verificación: cierra la sesión actual e inicia sesión con operario y la contraseña indicada. Debe poder entrar correctamente.

  4. Cambiar el nombre del equipo

    Windows 11

    Ve a Configuración → Sistema → Acerca de. Pulsa Cambiar nombre de este equipo y escribe AULA-XX.

    Comando PowerShell equivalente:

    Rename-Computer -NewName "AULA-XX" -Restart

    -NewName indica el nuevo nombre y -Restart reinicia el equipo para aplicar el cambio.

    Ubuntu 24.04

    Ejecuta en terminal:

    sudo hostnamectl set-hostname AULA-XX

    Comprueba con hostname que aparece AULA-XX.

    Verificación: en Windows, después del reinicio, abre Sistema → Acerca de y comprueba que el nombre es AULA-XX. En Ubuntu ejecuta hostname.

  5. Verificar red con DHCP

    Windows 11

    Ve a Configuración → Red e Internet → Ethernet o Wi-Fi → Propiedades. Comprueba que la asignación de IP es Automática (DHCP).

    Comando para ver la configuración:

    ipconfig /all

    /all muestra toda la información de red: IP, máscara, puerta de enlace y DNS.

    Ubuntu 24.04

    Ejecuta en terminal:

    nmcli con show --active

    Comprueba el nombre de la conexión activa. Después configura DHCP:

    nmcli con mod "Wired connection 1" ipv4.method auto

    Si el nombre de la conexión es distinto, sustitúyelo por el que hayas visto. También puedes renovar la IP con:

    sudo dhclient -v

    -v activa el modo detallado para ver lo que hace el comando.

    Verificación: ejecuta ping 192.168.10.1 para comprobar la puerta de enlace y ping www.google.es para comprobar DNS e Internet. Deben responder.

  6. Aplicar actualizaciones y comprobar protección básica

    Windows 11

    Ve a Configuración → Windows Update y pulsa Buscar actualizaciones. Espera a que termine y reinicia si es necesario.

    Abre Seguridad de Windows → Protección contra virus y amenazas. Comprueba que la protección está activa y pulsa Buscar actualizaciones en Definiciones de virus y amenazas.

    Ubuntu 24.04

    Ejecuta en terminal:

    sudo apt update

    sudo apt upgrade -y

    -y responde automáticamente sí a las preguntas de instalación. Para protección antivirus básica opcional:

    sudo apt install clamav -y

    sudo freshclam

    freshclam actualiza las definiciones de virus.

    Verificación: en Windows no deben quedar actualizaciones pendientes y la protección debe mostrar un icono verde. En Ubuntu el sistema debe indicar que no hay actualizaciones pendientes y freshclam debe completar sin errores.

Resolución de problemas · Nivel avanzado

AVANZADO

El equipo AULA-05 no tiene acceso a Internet. Al comprobar la IP en Windows con ipconfig o en Ubuntu con ip a, aparece una dirección 169.254.x.x. Además, la fecha es del año 2019, el teclado escribe símbolos en lugar de vocales acentuadas y el nombre del equipo es DESKTOP-ABC123.

Debes diagnosticar y corregir todos los fallos. Para cada síntoma indica: causa probable, comprobación realizada y solución aplicada. Después comprueba que el equipo navega correctamente.

Tarea nivel avanzado: entrega un informe de diagnóstico con capturas del estado anterior y del estado final después de tu intervención.

Preguntas de reflexión

  1. ¿Por qué una IP 169.254.x.x indica un fallo y no es válida en la red de la empresa?
  2. ¿Qué diferencia existe entre cerrar sesión y apagar el equipo para aplicar cambios de idioma?
  3. ¿Por qué el DNS es necesario para navegar con nombres de dominio aunque tengas IP y puerta de enlace configuradas?
  4. ¿Qué riesgos tiene dejar una cuenta de operario sin contraseña en un taller?
  5. ¿Por qué conviene activar las actualizaciones automáticas en equipos de producción?

Errores frecuentes y diagnóstico

  • Los menús están en inglés tras instalar Windows. Síntoma: textos en inglés. Solución: añadir Español en Configuración → Hora e idioma → Idioma y región, subirlo y cerrar sesión.
  • La letra ñ o los acentos escriben otro carácter. Síntoma: teclado en distribución inglesa. Solución: cambiar la distribución a Spanish (Spain) en Windows o usar localectl set-x11keymap es en Ubuntu.
  • La hora aparece desfasada. Síntoma: fecha o hora atrasada o adelantada. Solución: comprobar la zona horaria y activar el ajuste automático; en Ubuntu timedatectl set-timezone Europe/Madrid.
  • Sin conexión con IP 169.254.x.x. Síntoma: no navega. Solución: revisar cable, activar DHCP, renovar IP con ipconfig /release y ipconfig /renew en Windows o sudo dhclient -v en Ubuntu.
  • No puedes cambiar el nombre del equipo. Síntoma: acceso denegado. Solución: usar una cuenta de administrador y, en Windows, reiniciar después del cambio.

Práctica CE-b: Personalización del entorno de trabajo en Windows 11 y Ubuntu 24.04

CE-b · complementario · 2 sesiones

Escenario empresarial

La empresa TecnoAula Servicios Informáticos ha contratado a una nueva administrativa, Marta, que ocupará un despacho con dos equipos: uno con Windows 11 (IP 192.168.10.11) y otro con Ubuntu 24.04 (IP 192.168.10.12). Como auxiliar informático, debes dejar ambos equipos personalizados según sus preferencias antes de su incorporación.

Marta ha solicitado:

  • Fondo de escritorio con la imagen corporativa (ya descargada en C:\Wallpapers\corp.jpg en Windows y en /home/marta/Imágenes/corp.png en Ubuntu).
  • Tema oscuro en ambos sistemas.
  • Tamaño de letra un 20% mayor para mejorar la lectura.
  • Que los archivos PDF se abran con el lector rápido de cada sistema.
  • Activar el alto contraste en el equipo Ubuntu para facilitar su uso en el turno de tarde.

Objetivos

Al terminar esta práctica serás capaz de:

  • Cambiar el fondo de escritorio y el tema en Windows 11 y Ubuntu 24.04.
  • Configurar el tamaño del texto y la escala de la interfaz.
  • Establecer aplicaciones predeterminadas para tipos de archivo.
  • Aplicar opciones básicas de accesibilidad (alto contraste).
  • Verificar que los cambios se guardan correctamente por usuario.

Nivel básico Práctica guiada – Windows 11

  1. Cambiar el fondo de escritorio:
    • Abre Configuración con tecla Windows + I.
    • Ve a Personalización → Fondo.
    • En el desplegable Personalizar el fondo, elige Imagen.
    • Haz clic en Examinar y selecciona C:\Wallpapers\corp.jpg.

    Verificación: el escritorio debe mostrar la imagen corporativa de forma inmediata.

  2. Aplicar tema oscuro:
    • Dentro de Personalización, selecciona Temas.
    • En Elegir tema, marca Oscuro.

    Verificación: la barra de tareas y las ventanas cambian a tonos oscuros.

  3. Aumentar tamaño de texto:
    • En Configuración → Accesibilidad → Tamaño del texto.
    • Desliza el control hasta 120% y pulsa Aplicar.

    Verificación: las letras de menús y ventanas se ven más grandes.

  4. Establecer lector PDF predeterminado:
    • En Configuración → Aplicaciones → Aplicaciones predeterminadas.
    • Busca .pdf en la lista y haz clic en el programa actual.
    • Elige Microsoft Edge (o el lector rápido indicado).

    Verificación: al hacer doble clic en un archivo PDF se abre con el programa elegido.

Nivel básico Práctica guiada – Ubuntu 24.04

  1. Cambiar el fondo de escritorio:

    Abre una terminal con Ctrl + Alt + T y ejecuta:

    gsettings set org.gnome.desktop.background picture-uri 'file:///home/marta/Imágenes/corp.png'

    Comentario del comando:

    • gsettings: herramienta para modificar ajustes del escritorio GNOME.
    • set: indica que vamos a asignar un nuevo valor.
    • org.gnome.desktop.background: esquema que controla el fondo de pantalla.
    • picture-uri: clave que guarda la ruta de la imagen.
    • 'file:///home/marta/Imágenes/corp.png': ruta en formato URI (con file:// delante).

    Verificación: ejecuta gsettings get org.gnome.desktop.background picture-uri. Debe devolver la misma ruta.

  2. Aplicar tema oscuro: 
    gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'

    color-scheme indica si el sistema usa tonos claros ('prefer-light') u oscuros ('prefer-dark').

    Verificación: ejecuta gsettings get org.gnome.desktop.interface color-scheme. Debe devolver 'prefer-dark'.

  3. Aumentar tamaño de texto (escala de texto): 
    gsettings set org.gnome.desktop.interface text-scaling-factor 1.2

    El factor 1.2 significa un 20% más grande que el tamaño estándar (1.0).

    Verificación: en la terminal escribe gsettings get org.gnome.desktop.interface text-scaling-factor. Debe mostrar 1.2.

  4. Establecer lector PDF predeterminado: 
    xdg-mime default org.gnome.Evince.desktop application/pdf

    Comentario:

    • xdg-mime default: asigna una aplicación por defecto para un tipo de archivo.
    • org.gnome.Evince.desktop: archivo .desktop de la aplicación Evince (lector de PDF).
    • application/pdf: tipo MIME del archivo PDF.

    Verificación: ejecuta xdg-mime query default application/pdf. Debe responder org.gnome.Evince.desktop.

  5. Activar alto contraste: 
    gsettings set org.gnome.desktop.interface gtk-theme 'HighContrast'

    El tema HighContrast aplica colores de alto contraste a las ventanas y controles.

    Verificación: las ventanas cambian a un diseño con bordes y colores fuertemente contrastados.

Nivel avanzado Resolución de problemas

INCIDENCIA

Al intentar aplicar el fondo corporativo en el equipo Ubuntu, el comando gsettings set ... no da error, pero al reiniciar el equipo vuelve a aparecer el fondo por defecto. Además, al comprobar la ruta con gsettings get org.gnome.desktop.background picture-uri se obtiene 'file:///home/marta/Imágenes/corp.png', pero el archivo no se muestra.

Tu tarea es diagnosticar y corregir el fallo. Sigue estos pasos:

  1. Comprueba si el archivo corp.png existe realmente con ls -l /home/marta/Imágenes/corp.png. Si no existe, créalo o descárgalo.
  2. Verifica los permisos del archivo: ls -l /home/marta/Imágenes/corp.png. Si no eres el propietario o falta permiso de lectura, el sistema no podrá cargarlo.
  3. Corrige los permisos si es necesario con chmod 644 /home/marta/Imágenes/corp.png (lectura para todos, escritura solo para el propietario).
  4. Vuelve a aplicar el fondo y reinicia la sesión para comprobar que persiste.

Explica en la caja cuál era la causa más probable del fallo y qué pasos seguiste para resolverlo.

Errores frecuentes y diagnóstico

  • Síntoma: El fondo en Ubuntu no cambia tras ejecutar gsettings.
    Diagnóstico: La ruta del archivo está mal escrita o falta el prefijo file://. Revisa el comando y ejecuta gsettings get para ver el valor almacenado.
  • Síntoma: El tema oscuro se aplica solo a algunas aplicaciones y no a todo el sistema.
    Diagnóstico: Es posible que la aplicación no soporte el tema oscuro o necesite reiniciarse. Cierra y abre la aplicación o reinicia la sesión.
  • Síntoma: El alto contraste en Ubuntu hace ilegibles algunos botones.
    Diagnóstico: El tema HighContrast no siempre combina bien con todos los programas. Prueba con gsettings set org.gnome.desktop.interface gtk-theme 'Yaru-dark' y activa la opción de alto contraste desde Configuración → Accesibilidad → Ver.
  • Síntoma: En Windows el cambio de fondo no se guarda al reiniciar.
    Diagnóstico: Puede que el usuario no tenga permisos para modificar el fondo (política de equipo). Comprueba con el administrador si existe una directiva de grupo que lo impida.

Resolución de problemas · Fallos en producción

Durante una mañana de trabajo aparecen estos tres avisos en los equipos. Realiza un diagnóstico para cada uno y ejecuta la solución comprobando que desaparece el error.

Incidencia 1: No se puede copiar a la memoria USB en Windows

Al intentar copiar EjeRapido2026_respaldo.zip a E:, Windows muestra el mensaje El disco está protegido contra escritura. La copia no se completa.

chkdsk E: /f

La opción /f corrige errores del sistema de archivos que pueden dejar la USB en modo solo lectura.

  • Si el error continúa, prueba a expulsar la memoria con seguridad, reinicia el equipo y vuelve a conectarla.

Incidencia 2: No se puede eliminar un archivo en Ubuntu

Al ejecutar rm /media/alumno/EJE_USB/documentacion_cliente.zip aparece rm: no se puede borrar '...': sistema de archivos de solo lectura.

  • Comprueba cómo está montada la memoria USB:
mount | grep EJE_USB

Si aparece la opción ro significa que está montada como solo lectura.

  • Desmóntala y vuelve a montarla si fuese necesario. Según los permisos de la práctica, puede usarse:
umount /media/alumno/EJE_USB
sudo mount -o rw /dev/sdb1 /media/alumno/EJE_USB

La opción -o rw indica que el montaje sea de lectura y escritura.

Incidencia 3: La impresora HP no imprime desde Ubuntu

La impresora aparece en configuración, pero al mandar una página de prueba no sale ningún documento.

  • Comprueba el servicio de impresión:
systemctl status cups

El servicio cups es el encargado de gestionar la impresión en Ubuntu. Si no está activo, reinícialo:

sudo systemctl restart cups
  • Abre la cola de impresión de la impresora y cancela todos los trabajos atascados.
  • Verifica que la impresora está compartida en Windows y que la IP o el nombre del equipo es accesible desde Ubuntu.

Errores frecuentes y diagnóstico

  • Error de sintaxis en rutas con espacios.
    Si una ruta contiene espacios, los comandos copy, move, mkdir, cp o mv la interpretan mal. Se soluciona encerrando la ruta entre comillas dobles.
  • El comando zip no se encuentra en Ubuntu.
    Aparece bash: zip: no se reconoce. Se instala con sudo apt install zip y se vuelve a ejecutar la orden.
  • No se puede eliminar una carpeta con rmdir.
    rmdir solo elimina carpetas vacías. Si contiene archivos o subcarpetas, debe usarse rmdir /s carpeta en Windows o rm -r carpeta en Linux.
  • El ZIP no se abre o parece dañado.
    Puede que la copia a la USB se interrumpiera o que la unidad se extrajera sin expulsión segura. Se verifica con unzip -t EJE2025_respaldo.zip en Ubuntu y con el asistente de extracción en Windows.
  • La impresora no aparece en Ubuntu.
    Normalmente se debe a que el firewall bloquea la red o a que la impresora no está compartida en Windows. Hay que comprobar la compartición y el estado de cups.

Práctica CE-f: Exploración de soportes de almacenamiento en un entorno mixto Windows y Ubuntu

CE-f · importante · 3 sesiones

3 sesiones
IMPORTANTE

Esta práctica se desarrolla en un aula con equipos que tienen arranque dual o máquinas virtuales con Windows 11 y Ubuntu 24.04. No se manipularán discos duros reales, solo se explorarán soportes ya montados. Está prohibido formatear, eliminar o modificar particiones sin autorización expresa del profesor.

Escenario empresarial

La empresa Vega Informática S.L., dedicada al mantenimiento de equipos en pequeñas oficinas, ha recibido el encargo de inventariar el almacenamiento de dos ordenadores de una gestoría: PC-GEST-01, con Windows 11 Pro (disco principal SSD de 256 GB y disco secundario HDD de 1 TB), y PC-GEST-02, con Ubuntu 24.04 LTS (disco SSD NVMe de 512 GB). Errores frecuentes y diagnóstico

Durante la práctica, es habitual cometer los siguientes errores. Si te ocurren, aplica la solución indicada.

  • Error 1: No aparece el USB en «Este equipo» de Windows aunque está conectado.
    Síntoma: En el Explorador de archivos no se ve ninguna unidad nueva.
    Solución: Abre Administración de discos y comprueba si el disco aparece sin letra o sin inicializar. Si tiene partición pero sin letra, asígnale una letra con clic derecho → Cambiar letra y rutas de acceso. Si no está inicializado, habría que inicializarlo (solo con permiso del profesor).
  • Error 2: En Ubuntu, el USB no aparece en lsblk.
    Síntoma: La salida de lsblk no muestra ningún dispositivo nuevo.
    Solución: Desconecta y reconecta el USB. Espera unos segundos y vuelve a ejecutar lsblk. Si sigue sin aparecer, prueba en otro puerto USB o comprueba si el USB funciona en otro equipo (podría estar dañado).
  • Error 3: En df -h no aparece una partición que sí se ve en lsblk.
    Síntoma: En lsblk existe la partición, pero en df -h no hay ninguna línea con ese punto de montaje.
    Solución: La partición no está montada. Se puede montar desde la aplicación Discos o con el comando sudo mount /dev/sdc1 /media/alumno/externo (siendo /dev/sdc1 la partición y /media/alumno/externo una carpeta existente). Nunca montar en una carpeta que no exista; créala antes con mkdir.
  • Error 4: Confundir disco físico con partición.
    Síntoma: El alumno dice que hay tres discos cuando en realidad hay un solo disco con tres particiones.
    Solución: En Administración de discos, los discos físicos son los que aparecen como Disco 0, Disco 1, etc., en la fila izquierda del panel inferior. Las particiones son divisiones dentro de cada disco, representadas como rectángulos dentro de la fila del disco. En lsblk, los discos físicos tienen TYPE="disk" y las particiones TYPE="part".
  • Error 5: Cerrar la ventana de Propiedades en Windows sin anotar el sistema de archivos.
    Síntoma: El alumno no recuerda si era NTFS o FAT32.
    Solución: Vuelve a abrir Propiedades de la unidad y anota el dato en el ejercicio. Es un dato clave para el informe.

Escenario empresarial

La empresa de servicios informáticos El Puente Digital S.L. gestiona el aula de informática del IES Ciudad del Mar. Trabajas como auxiliar informático y tienes asignados dos equipos:

  • PC-Windows 11 con IP 192.168.10.101 y carpeta de datos C:\Taller\Datos.
  • PC-Ubuntu 24.04 con IP 192.168.10.102 y carpeta de datos /home/alumno/Taller/Datos.

Un alumno ha conectado un USB sospechoso y tememos que pueda contener malware. Además, la jefa de estudios ha pedido que los datos de facturación de prácticas no se pierdan bajo ningún concepto. Tienes que:

  • Configurar y utilizar antivirus en ambos sistemas.
  • Analizar las carpetas de datos.
  • Realizar una copia de seguridad en un disco USB externo.

El disco USB se verá como E: en Windows y se montará en el punto de montaje /mnt/backup en Ubuntu.

Objetivos de la práctica

  • Comprobar la protección en tiempo real y actualizar las definiciones de Microsoft Defender en Windows 11.
  • Lanzar análisis rápidos y personalizados sobre carpetas concretas.
  • Instalar ClamAV y ClamTk en Ubuntu 24.04 y actualizar la base de firmas.
  • Analizar carpetas locales con clamscan.
  • Montar y desmontar correctamente un punto de montaje en Linux para copias de seguridad.
  • Realizar y verificar copias de seguridad con robocopy en Windows y tar en Linux.
  • Documentar los resultados y diagnosticar errores típicos.

Práctica guiada · Nivel básico

Parte A. Antivirus en Windows 11: Microsoft Defender

Paso 1. Abrir PowerShell como administrador.
Haz clic derecho en el botón Inicio y selecciona Terminal (Administrador) o Windows PowerShell (Administrador).

Verificación: Aparecerá una ventana con la ruta PS C:\Windows\system32> o similar, indicando que tienes permisos elevados.

Paso 2. Comprobar el estado de Microsoft Defender.
Escribe el siguiente comando:

Get-MpComputerStatus | Select-Object AntivirusEnabled, RealTimeProtectionEnabled, AntivirusSignatureLastUpdated
  • Get-MpComputerStatus: muestra el estado completo de Microsoft Defender.
  • |: tubería, envía el resultado al siguiente comando.
  • Select-Object: selecciona solo las propiedades indicadas.

Verificación: Debes obtener AntivirusEnabled = True y RealTimeProtectionEnabled = True. Si alguno aparece False, hay un problema de configuración que debes corregir antes de continuar.

Paso 3. Actualizar las definiciones de virus.
Ejecuta:

Update-MpSignature

Este comando descarga las últimas firmas de malware.

Verificación: No debe mostrar errores. Vuelve a ejecutar el comando del paso 2 y comprueba que la fecha AntivirusSignatureLastUpdated ha cambiado.

Paso 4. Lanzar un análisis rápido.
Ejecuta:

Start-MpScan -ScanType QuickScan
  • -ScanType QuickScan: indica que queremos un análisis rápido de las zonas más vulnerables.

Verificación: El comando muestra el progreso y termina sin amenazas detectadas.

Paso 5. Análisis personalizado de la carpeta de datos.
Ejecuta:

Start-MpScan -ScanType CustomScan -ScanPath C:\Taller\Datos
  • -ScanType CustomScan: análisis personalizado.
  • -ScanPath: ruta concreta que queremos analizar.

Verificación: Debe finalizar indicando amenazas detectadas: 0 o similar, o bien mostrar un resumen sin archivos infectados.

Ejercicio 1. Anota los valores devueltos por Get-MpComputerStatus y el resultado del análisis personalizado. ¿Cuántas amenazas detectó?

Parte B. Antivirus en Ubuntu 24.04: ClamAV

Paso 1. Abrir la terminal.
Pulsa Ctrl+Alt+T.

Paso 2. Instalar ClamAV y ClamTk.
Ejecuta:

sudo apt update && sudo apt install clamav clamtk -y
  • sudo: ejecuta el comando con privilegios de administrador.
  • apt update: actualiza la lista de paquetes disponibles.
  • &&: encadena comandos; el segundo solo se ejecuta si el primero termina sin errores.
  • apt install clamav clamtk: instala el motor antivirus y su interfaz gráfica.
  • -y: responde automáticamente sí a las preguntas.

Verificación: Al finalizar, comprueba la versión con:

clamscan --version

Debe mostrar un número de versión sin errores.

Paso 3. Actualizar la base de firmas de ClamAV.
Para evitar conflictos con el servicio automático, ejecuta:

sudo systemctl stop clamav-freshclam
sudo freshclam
  • systemctl stop clamav-freshclam: detiene el servicio que actualiza automáticamente las firmas.
  • freshclam: descarga manualmente la base de datos de firmas.

Verificación: Debe aparecer un mensaje indicando que la base de datos se ha actualizado, por ejemplo Database updated....

Paso 4. Analizar la carpeta de datos.
Ejecuta:

clamscan -r -i /home/alumno/Taller/Datos
  • -r: analiza de forma recursiva las subcarpetas.
  • -i: muestra solo los archivos infectados, no todos los analizados.

Verificación: Al final debe aparecer Infected files: 0. Si aparece un número mayor que 0, anótalo y avisa al profesor.

Ejercicio 2. Pega la última línea de salida de clamscan y explica qué significa cada campo.

Parte C. Copias de seguridad
C.1. Copia de seguridad en Windows con robocopy

Paso 1. Conectar y comprobar el USB.
Conecta el disco USB y ejecuta en PowerShell:

Get-Volume

Verificación: Debe aparecer una unidad E: con sistema de archivos FAT32, exFAT o NTFS y tamaño adecuado.

Paso 2. Realizar la copia espejo.
Ejecuta:

robocopy C:\Taller\Datos E:\Backup\Datos /MIR /R:2 /W:5 /LOG:C:\Taller\backup.log /TEE
  • robocopy: herramienta de copia de archivos robusta de Windows.
  • C:\Taller\Datos: carpeta de origen.
  • E:\Backup\Datos: carpeta de destino en el USB.
  • /MIR: copia espejo, replica el origen en el destino y elimina del destino lo que ya no esté en origen.
  • /R:2: reintenta 2 veces los archivos con error.
  • /W:5: espera 5 segundos entre reintentos.
  • /LOG:C:\Taller\backup.log: guarda el resultado en un archivo de registro.
  • /TEE: muestra el resultado también en pantalla.

Verificación: Al final del registro aparecerá un resumen con número de archivos copiados, omitidos y errores. Debe haber 0 errores.

Paso 3. Verificar la copia.
Ejecuta:

Get-ChildItem E:\Backup\Datos

Verificación: Deben aparecer los mismos archivos que en C:\Taller\Datos.

C.2. Copia de seguridad en Ubuntu con tar y punto de montaje

Paso 1. Identificar el USB.
Conecta el USB y ejecuta:

lsblk

Verificación: Debe aparecer un dispositivo como /dev/sdb1 con el tamaño aproximado del USB.

Paso 2. Crear el punto de montaje y montar el USB.
Ejecuta:

sudo mkdir -p /mnt/backup
sudo mount /dev/sdb1 /mnt/backup
  • mkdir -p: crea el directorio si no existe; -p crea también los directorios intermedios.
  • /mnt/backup: punto de montaje para el USB.
  • mount: monta el dispositivo indicado en el punto de montaje.

Verificación: Ejecuta:

mount | grep /mnt/backup

Debe aparecer una línea con /dev/sdb1 on /mnt/backup.

Paso 3. Crear la copia comprimida.
Ejecuta:

tar -czvf /mnt/backup/datos-alumno-$(date +%F).tar.gz /home/alumno/Taller/Datos
  • tar: crea archivos comprimidos.
  • -c: crear archivo nuevo.
  • -z: comprimir con gzip.
  • -v: mostrar archivos procesados.
  • -f: indicar el nombre del archivo de destino.
  • $(date +%F): añade la fecha actual al nombre, por ejemplo datos-alumno-2025-04-08.tar.gz.

Verificación: Comprueba que el archivo se ha creado:

ls -lh /mnt/backup

Debe aparecer el archivo datos-alumno-*.tar.gz con un tamaño razonable.

Paso 4. Verificar el contenido de la copia.
Ejecuta:

tar -tzf /mnt/backup/datos-alumno-$(date +%F).tar.gz | head
  • -t: lista el contenido del archivo comprimido.
  • | head: muestra solo las primeras líneas.

Verificación: Deben aparecer algunos nombres de archivos de la carpeta original.

Paso 5. Desmontar el USB.
Ejecuta:

sudo umount /mnt/backup

Verificación: Vuelve a ejecutar:

mount | grep /mnt/backup

No debe mostrar nada.
